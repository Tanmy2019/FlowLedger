认证与权限体系

登录流程

访问 /  →  登录页  →  输入邮箱+密码  →  创建/加入账本
                        │
                  初始用户 → 创建默认账本 + 默认分类
                  受邀用户 → 接受邀请加入已有账本

认证方案：NextAuth v5

登录方式
  • 邮箱+密码登录（凭证登录）
  • JWT Session（无数据库 session）
  • 支持后续扩展 OAuth
权限校验
  • API 中间件校验 JWT
  • 每个 API 请求校验：用户是否在该账本中
  • 写操作校验：role !== viewer
  • 管理操作校验：role === owner

邀请流程

Owner → 发送邀请链接（含token）
  → 受邀用户点击链接 → 如果已有账号直接加入
                      → 如果无账号先注册再加入
  → 加入后默认为 viewer 角色
  → Owner 可调整角色权限

账本切换

侧边栏顶部账本下拉切换
├── 家庭账 (当前)
├── 旅行账
├── 生意账
└── [+ 新建账本]

切换后：所有数据（流水/账户/预算/统计）跟随账本切换
数据完全隔离
