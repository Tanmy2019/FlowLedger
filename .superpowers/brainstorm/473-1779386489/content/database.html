数据库设计

Prisma Schema — 核心模型关系

用户与账本

User ──< Ledger ──< Transaction
 │        │            │
 │        │            ├──> Category (分类)
 │        │            ├──> Account  (账户)
 │        │            ├──> Tag      (标签)
 │        │            └──> Member   (成员,多人账本)
 │        │
 │        ├──> Budget       (预算)
 │        ├──> Template     (记账模板)
 │        └──> Rule         (自动分类规则)
 │
 └── LedgerMember (账本成员关联)

核心表清单

User — id, name, email, passwordHash, createdAt
Ledger — id, name, type(家庭/旅行/生意), icon, color, ownerId, createdAt
Transaction — id, ledgerId, type(收入/支出/转账), amount, date, note, categoryId, accountId, toAccountId(转账目标), memberId, merchant, project, createdAt
Category — id, ledgerId, name, parentId(二级分类), type(收入/支出), icon, color, sortOrder
Account — id, ledgerId, name, type(现金/银行卡/信用卡/支付宝/微信/投资/负债), balance, initialBalance, icon, color, sortOrder
Budget — id, ledgerId, name, amount, period(月/年/自定义), startDate, endDate, categoryId(可选), type(必要/非必要/全部)
Tag — id, ledgerId, name, color
TransactionTag — transactionId, tagId (多对多关联)

账多用户权限模型

LedgerMember
├── userId      → 用户
├── ledgerId    → 账本
├── role        → owner / editor / viewer
└── joinDate

权限规则:
- owner: 完全控制，可删除账本、管理成员
- editor: 可记账、编辑、删除自己的记录
- viewer: 仅可查看统计和流水（不可增删改）
